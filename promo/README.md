# promo — графика akov.tech для презентаций и брендинга

PNG с прозрачным фоном. Все QR ведут на https://akov.tech и проверены сканером macOS (Vision).

## Контактные плашки (вставлять в конец презентации)

| Файл | Куда ставить | Взгляд |
|---|---|---|
| `contact-left.png` (1579×500) | левый край слайда | вправо, в контент |
| `contact-right.png` (1579×500) | правый край слайда | влево, в контент |
| `contact-vertical-left.png` (500×1047) | вертикальная, левый край | вправо |
| `contact-vertical-right.png` (500×1047) | вертикальная, правый край | влево |

Дизайн: «увеличенная фавиконка» — тёмная плита #111, три фирменных квадрата по углам,
имя Helvetica UltraLight, URL с приглушённым `https://`, QR с тремя цветными «глазами».
В вертикальных: имя (2 строки), URL и QR-плитка выровнены в одну ширину попиксельно.

## Лого-локап

- `logo-on-dark.png` — белая версия, класть на тёмные фоны
- `logo-on-light.png` — тёмная версия, класть на светлые фоны

«АЛЕКСЕЙ КОВАЛЕВ» (Helvetica Light, разрядка) + `https://akov.tech` (SF Condensed),
ширины строк совпадают попиксельно.

## Служебное

- `font-variants/` — образцы горизонтальной плашки в 5 шрифтах (выбран helvetica-ultralight)
- `design-philosophy.md` — дизайн-манифест графики
- Генераторы: `../tools/contact_badge.py` (плашки; запуск: `python3 tools/contact_badge.py helvetica-ultralight`,
  образцы шрифтов: `... sampler`) и `../tools/logo_lockup.py` (лого)
